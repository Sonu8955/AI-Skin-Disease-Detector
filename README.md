# AI Skin Disease Detector 

An AI-powered web application that detects skin diseases from uploaded images using Deep Learning and CNN (Convolutional Neural Network).

##  Features

* Upload skin disease image
* AI-based disease prediction
* Confidence percentage display
* CNN Deep Learning model
* Flask web application
* Simple and user-friendly UI

## 🛠 Technologies Used

* Python
* Flask
* TensorFlow
* Keras
* CNN
* HTML
* CSS

## How to Run

1. Install dependencies

pip install flask tensorflow numpy pillow matplotlib opencv-python

2. Run the Flask app

python app.py

3. Open browser

http://127.0.0.1:5000

##  AI Model

The project uses a CNN (Convolutional Neural Network) model trained on skin disease images to classify diseases like:

* Acne
* Eczema
* Psoriasis
* Ringworm

##  Output

The application predicts:

* Disease name
* Confidence percentage
